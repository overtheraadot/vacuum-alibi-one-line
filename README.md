One line, at most 200 characters, in which a robot vacuum explains why it missed a spot — with a charging-dock alibi and a dust-bunny witness.

## The entry

`main.py` writes exactly one original line to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> Charging dock records show I was plugged in from 22:00 to 06:00 — the dust under the sofa can testify I never left.

115 characters, one line. The joke: deadpan machine voice (charging logs, exact hours), and the turn — the dust itself testifies the vacuum never left the dock.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
